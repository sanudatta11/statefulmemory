# memlayer

Persistent memory infrastructure for coding agents: **CLI + MCP → gRPC daemon →
per-project SQLite**. **Self-host** on your machine or team, or use
**Memlayer Cloud** (managed SaaS).

## Install in one minute

```bash
git clone https://github.com/sanudatta11/memlayer && cd memlayer
make prereqs && make install
export PATH="$HOME/.local/bin:$PATH"
memlayer --version
```

## Use it

1. **Wire your agent** — `memlayer install` (or `memlayer install --agent cursor`)
2. **Save something useful** — `memlayer obs save --type decision --title "…" --content "…"` (add `--anchor path::symbol` for code-tied claims)
3. **Pull context later** — `memlayer obs context --query "…" --limit 20`

Full walkthrough: [Getting started](/docs/getting-started/) · Agent setup:
[Wire into your agent](/docs/agents/) · Shipped vs wishlist:
[Integrations](/docs/integrations/).

Works with Claude Code, Cursor, Windsurf, Antigravity, OpenCode, Kimi Code,
ZCode, VS Code / Copilot, Codex, Gemini CLI, Amazon Q, and any agent that can
shell out or speak MCP. There is no Python Memory SDK yet — use MCP or the
CLI. Deployment: [Self-hosting and Cloud](/docs/self-hosting/).
