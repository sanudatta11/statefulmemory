# memlayer

Persistent memory for AI coding agents: **local**, per-project, no cloud.

Save decisions and fixes once. Next session, your agent can search and pull the
right context through MCP or the CLI.

## Install in one minute

```bash
git clone https://github.com/sanudatta11/memlayer && cd memlayer
make prereqs && make install
export PATH="$HOME/.local/bin:$PATH"
memlayer --version
```

## Use it

1. **Wire your agent** — `memlayer install` (or `memlayer install --agent cursor`)
2. **Save something useful** — `memlayer obs save --type decision --title "…" --content "…"`
3. **Pull context later** — `memlayer obs context --query "…" --limit 20`

Full walkthrough: [Getting started](/docs/getting-started/) · Agent setup: [Wire into your agent](/docs/agents/)

Works with Claude Code, Cursor, Windsurf, Antigravity, OpenCode, Kimi Code,
ZCode, VS Code / Copilot, Codex, Gemini CLI, and any agent that can shell out
or speak MCP. Local and open-source models: pin
`MEMLAYER_LLM_*` (see [Wire into your agent](/docs/agents/)).
