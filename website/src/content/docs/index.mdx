## Chat history is not project memory

Your agent's chat log dies with the window. Every new session, it re-learns the
same decisions, re-trips the same pitfalls, and drifts on the same open
questions. StatefulMemory keeps the durable record: what you decided, why, and
which code it is pinned to — then hands the agent the right context the next
time it starts.

Long context models still pay attention cost inside the window.
[Effective context](/docs/search-context/) compiles decisions, anchors, and
facts into a fixed host window, so a 200k or 1M-token agent acts like a much
larger working set.

## How it works

<CardGrid>
  <Card title="Remember">
    <code>smem obs save --type decision --title "use pgx not GORM"</code>
    — every choice lands in per-project SQLite, optionally pinned to code.
  </Card>
  <Card title="Retrieve">
    <code>smem obs context --query "which ORM should we use?"</code>
    — hybrid BM25 + dense, token-budgeted, ranked for the task at hand.
  </Card>
  <Card title="Verify">
    <code>smem obs save --anchor src/auth.rs::login …</code>
    — git hooks re-check anchors; stale claims are withdrawn from context.
  </Card>
  <Card title="Decide">
    <code>smem decide "SQLite or Postgres?"</code>
    — conflicting memories get a typed verdict: in force, superseded, archived.
  </Card>
  <Card title="Connect">
    <code>smem graph query auth --hops 2</code>
    — entity graph with PPR ranking surfaces related decisions you forgot existed.
  </Card>
  <Card title="Laya">
    <code>smem install</code>
    — a System-1 sidecar that answers router / decide / conflict questions
    locally, with silent fallback. Full story on the [Laya page](/docs/laya/).
  </Card>
</CardGrid>

## Own your memory

<CardGrid>
  <Card title="Self-host">
    Daemon on your laptop (Unix socket) or team TCP+TLS. Data stays yours —
    inspect, backup, delete.
  </Card>
  <Card title="StatefulMemory Cloud">
    Same CLI and MCP surfaces, hosted storage and ops, when you would rather
    not run the daemon.
  </Card>

    Export a `.mem` archive and import anywhere. Your memory follows you, not a
    vendor's lock-in.
