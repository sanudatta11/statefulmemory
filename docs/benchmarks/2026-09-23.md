## How to read this

The headline retrieval signal is **92.33% Recall@k**, with **0.6500 MRR** and **67.6% accuracy** across 1,538 scored queries.

The run also shows that **45.4% of queries skipped reranking**, while the reranked path has a materially larger latency contribution than raw retrieval:

- Retrieval: 131.60 ms p50 / 314.79 ms p95
- Rerank: 11.75 s p50 / 64.44 s p95
- End-to-end: 38.76 s p50 / 147.21 s p95

This makes reranker selectivity and latency an obvious optimization target for subsequent experiments.

## Reproducibility note

These values are an evaluation snapshot from the project, provided together with the benchmark request. Treat them as a point-in-time measurement, not as a claim of superiority over another memory system.

For comparisons with published benchmark numbers from other projects, use the same dataset, query set, retrieval budget, judge/answer models, scoring rules, and disclosed methodology.
